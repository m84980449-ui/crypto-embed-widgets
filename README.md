# 🌌 CryptoEmbed — Glassmorphic Embeddable Crypto Widgets

A set of premium, high-fidelity glassmorphic price widget cards that bloggers, community managers, or developers can embed on their websites.

---

## 🚀 Key Features

* **Real-time Price Sync**: Directly connected with Binance public CORS-enabled API to pull live asset prices.
* **Glassmorphic Aesthetics**: Modern transparent and glowing UI that blends into any dark mode blog or portal.
* **Integrated Monetization**: Hardcoded with active Binance referral banners linked with your affiliate account ID.

---

## 🛠️ Usage

Simply select your token on the generator dashboard and copy the `<iframe>` tag to paste it anywhere:

```html
<iframe src="https://m84980449-ui.github.io/crypto-embed-widgets/widget.html?token=BTC" width="100%" height="180" style="border:none; max-width:320px;" scrolling="no"></iframe>
```
